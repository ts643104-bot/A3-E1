# A3&E1: English for MIS

نموذج أولي متجاوب لتعلّم الإنجليزية عبر مهام من نظم المعلومات الإدارية. الواجهة عربية RTL، والمواقف والتمارين التقنية باللغة الإنجليزية.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يعرضه Vite. للبناء والتحقق:

```bash
npm run build
npm run lint
```

## Android APK

يتطلب البناء JDK 21 وAndroid SDK Platform 36 وBuild Tools 36.0.0، مع قبول تراخيص Android SDK مرة واحدة. بعد إعداد `JAVA_HOME` و`ANDROID_HOME`:

```powershell
npm run android:apk
```

ينتج ملف Debug APK في `android/app/build/outputs/apk/debug/app-debug.apk`. انقله إلى الهاتف وافتحه ثم وافق على التثبيت من هذا المصدر. هذه نسخة Debug وليست مخصصة للنشر على Google Play.

### APK عبر GitHub Releases

بعد رفع المستودع إلى GitHub:

- من تبويب **Actions** شغّل **Build Android APK**؛ ستجد الملف في Artifacts.
- أو أنشئ Tag وادفعه، مثلاً `git tag v1.0.0` ثم `git push origin v1.0.0`؛ سيبني Workflow الـAPK وينشره في **Releases**.

إصدار Actions الحالي موقّع بمفتاح Debug مؤقت؛ تثبيت إصدار أحدث فوق إصدار سابق قد يتطلب حذف النسخة السابقة. للنشر العام أو تحديثات سلسة، يلزم إعداد مفتاح Release ثابت في GitHub Secrets.

## الموجود في النموذج

- شاشة شروط وأحكام تتطلب الوصول لنهاية النص قبل تفعيل الموافقة.
- تسجيل/دخول متدرّب على هذا الجهاز، مع مشتق كلمة مرور PBKDF2 بدلاً من تخزينها كنص.
- إضافة موعد أسبوعي لكل درس مع يوم ووقت ومدة، وحفظ محلي.
- تذكير داخل التطبيق عند حلول الموعد، وإشعار متصفح اختياري إذا سمح النظام.
- لوحة يومية وتحدٍ صوتي عن SQL.
- مسارات Database Management وSystems Analysis وIT Project Management وE-Commerce.
- 20 درساً متدرجاً من A1 إلى C1، بواقع 5 دروس لكل مجال MIS.
- 4 مشروعات مكثفة بمستوى C1، مدة كل منها 25 دقيقة، مع مرشحات للمجال والمستوى والنمط المكثف.
- وضع كتابة مع مراجعة محلية تجريبية لمصطلحات المهمة.
- تسجيل صوت فعلي عبر MediaRecorder مع معالجة الصدى والضوضاء والكسب التلقائي عند دعم الجهاز، ثم تشغيل الملف أو تنزيله أو إعادة تسجيله.
- تصنيف المسارات حسب مجال MIS ومستوى CEFR المتوقع.
- جلسة تركيز بمؤقت وإيقاف اختياري، ونقاط خبرة محفوظة محلياً.
- صفحات للمسارات والتقدم، وتخطيط متجاوب للهاتف وسطح المكتب.

## حدود النسخة

هذه واجهة MVP دون خادم. الحساب وتحقق كلمة المرور محليان في هذا المتصفح وليسا مصادقة خادمية أو مزامنة بين الأجهزة. التسجيل الصوتي يبقى محلياً ولا يُرفع؛ يحتاج إذن الميكروفون وسياقاً آمناً (HTTPS أو localhost). لا يقيس مخارج الحروف أو النبر، ومراجعة الكتابة ليست نموذج ذكاء اصطناعي. المواعيد والتنبيهات تعمل عندما تكون الصفحة مفتوحة؛ لا يستطيع تطبيق ويب تشغيل نفسه إجبارياً إذا أُغلق، أو حبس الهاتف حتى نهاية الدرس. بيانات التقدم محفوظة محلياً.

للوصول إلى منتج كامل، يلزم ربط API وخدمة تقييم نطق على مستوى الصوتيات، ومدقق كتابة سياقي، وتخزين آمن وموافقة صريحة. القفل على مستوى النظام يتطلب واجهات وصلاحيات إدارة تختلف بين Android وiOS، ولا يمكن فرضه من تطبيق ويب عادي.
